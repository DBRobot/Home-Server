The AppImage needs no install: make it executable and run it. Android asks you to allow installing from outside its store, once; there is no listing to install from, because this is not a product.

This is {{ tag }}, built from the source at that commit, by the same commands you can run. Every file offered here is named, with its SHA-256, in a manifest signed with the fleet's release key - the key that signs what the boxes themselves run - and a file that is not in it is not offered. The short code under each button is the start of that hash. Nothing in the app is a secret: it makes its own key on your device the first time you open it, and that key never leaves.

The Windows installer carries WinFsp — Windows File System Proxy, Copyright © Bill Zissimopoulos, which is what lets your library appear as a drive there, and rclone, which puts it there.
